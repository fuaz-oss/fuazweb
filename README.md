# FUAZ Website

The Federal University of Agriculture, Zuru website is a static Astro site.

## Requirements

- Node.js 22.12 or newer
- Bun

## Development

```sh
bun install
bun run dev
```

## Build and preview

```sh
bun run build
bun run preview
```

The static site is generated in `dist/` and can be deployed to any static web host. No runtime secrets, database, or server adapter are required.

Contact enquiries use email links, and student services link to the official student portal.
